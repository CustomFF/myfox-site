MyFox

MyFox — это переработка интерфейса и настроек Firefox плюс утилита для установки браузера и управления им.

MyFox is a rework of the Firefox interface and settings plus a utility that installs the browser and manages it.

Интерфейс становится компактнее и удобнее: вкладки и меню без лишних отступов, загрузки, расширения и переводчик в боковой панели. ИИ-функции и телеметрия по умолчанию выключены.

The interface gets more compact and easier to use: tabs and menus without extra padding, downloads, extensions and the translator in the sidebar. AI features and telemetry are off by default.

УстановкаInstall

На Linux MyFox ставится одной командой. Он скачивает официальный релиз Firefox в домашнюю папку и применяет MyFox tweaks. Профиль уже установленного Firefox можно скопировать вместе со входом в аккаунт Firefox. Сам тот Firefox и его профили не затрагиваются. Потом MyFox обновляет MyFox tweaks и управляет профилями. На Windows и macOS MyFox tweaks можно попробовать поставить вручную, там они не проверялись.

On Linux MyFox installs with one command. It downloads the official Firefox release into the home folder and applies MyFox tweaks. The profile of a Firefox already installed can be copied, signed-in Firefox account included. That Firefox itself and its profiles are not affected. Later MyFox updates MyFox tweaks and manages profiles. On Windows and macOS MyFox tweaks can be tried manually; they have not been tested there.

Требования: Linux (x86_64 или aarch64), Python 3.8 или новее, curl.Requirements: Linux (x86_64 or aarch64), Python 3.8 or newer, curl.

Выполните команду в терминале.Run the command in a terminal.

$ curl -sL myfox.in | sh

Установка происходит без взаимодействия с пользователем. Параметры установки по умолчанию, а также флаги для их изменения можно посмотреть в документации MyFox.

The install runs without user interaction. The default install options and the flags to change them are listed in the MyFox documentation.

При установке в MyFox можно скопировать профиль уже установленного Firefox со всеми закладками, паролями, историей, расширениями и аккаунтом Firefox. Позже профиль можно скопировать или перенести командой myfox или на странице about:myfox.

During the install, the profile of a Firefox already installed can be copied into MyFox, with all its bookmarks, passwords, history, extensions and Firefox account. Later a profile can be copied or moved with the myfox command or on the about:myfox page.

В меню ярлыка Firefox, кроме стандартных пунктов, есть настройки, перезапуск Firefox и обновление MyFox. Для управления MyFox используется команда myfox.

Besides the standard items, the Firefox shortcut menu has settings, a Firefox restart and a MyFox update. MyFox is managed with the myfox command.

Firefox обновляется сам. Твики, темы и MyFox обновляются командой myfox refresh, из меню ярлыка или из раздела обновлений на странице about:myfox.

Firefox updates itself. The tweaks, the themes and MyFox update with myfox refresh, from the shortcut’s menu or from the updates section of the about:myfox page.

УдалениеUninstalling

По умолчанию при удалении MyFox профиль браузера сохраняется. Это поведение можно изменить, задав параметры в диалоге удаления или через флаги командной строки.

By default, uninstalling MyFox keeps the browser profile. You can change this with the uninstall options, in the dialog or with command-line flags.

Параметры установки и удаления описаны в документации MyFox.

The install and uninstall options are described in the MyFox documentation.
